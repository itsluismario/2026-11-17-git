# Learning about Version Control

Author: Luis Mario

Solving merge conflicts takes conscious effort, but I can do it!

What I like most about version control is that I don't have to remember everything I've done: with good practices, I can always go back if anything goes wrong.
What I find most challenging is knowing when to use `git pull --no-rebase`. I understand the concept, but I'm still figuring out how to apply it in practice.
